Features

Vehicle routing with time windows and capacity constraints.

Interactive Maps

Folium maps to explore “Before” and “After” routes.

KPIs & Export

Distance, travel/service time, and downloadable JSON.

How it works

  1. Generate a mock scenario around a depot with customer demands and time windows.
  2. Estimate distances and travel times from Haversine + average speed.
  3. Run a greedy baseline and an OR-Tools optimization.
  4. Visualize and compare KPIs and route maps.

Get started

pip install -r ../requirements.txt
streamlit run ../src/app.py

Once the dashboard is running, open http://localhost:8501. To generate artifacts via CLI:

python ../src/run_pipeline.py

Outputs will appear in ../outputs/. If maps were generated, you can open:

  • Baseline Map
  • Optimized Map
